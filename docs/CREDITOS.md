# Créditos de assets

## Assets externos

**Nenhum.** Todas as cenas 3D, texturas, shaders, iluminação (HDRI procedural via `Lightformer`) e capas são geradas por código neste repositório. Não há modelos GLB, texturas, HDRIs, fontes ou sons de terceiros no redesign.
